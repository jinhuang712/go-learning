Go Learning · 资深 Java 工程师的 Go 进阶之路

面向有 Java 高并发分布式微服务经验的资深后端工程师,目标:在大厂微服务场景下独立 阅读、设计、评审、优化 极致 Go 代码。本项目以 Unit → Lesson → Section 三级架构组织,所有示例可运行、可测试。

本仓库目标 抛弃 面向对象/异常流 的 Java 心智,拥抱 组合 / 鸭子接口 / 多返回值 error / CSP 并发。每节都带 Java 对照、运行示例与坑点。

⚙ 环境要求

  • Go ≥ 1.20
  • 推荐 GoLand / VS Code + Go 插件
  • 建议:开启 gofmt 自动格式化、golangci-lint 静态检查

图 1 · Java 概念到 Go 的迁移映射
Java 概念Go 对应本质差异
Classstruct + 方法无继承,仅组合
interfaceinterface隐式实现 · 鸭子类型
extends匿名嵌入语法糖,非父子关系
