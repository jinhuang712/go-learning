Lesson 0 · Go Package 系统详解

本课程为 Java 开发者建立 Go Package / Import / Module / Visibility 的完整心智模型,并把所有概念与 Maven/Gradle、JDK 包系统一一对照。

学习地图 Package 是 Go 代码的基本组织单元,Import 是引用机制,Module 是项目级依赖管理,而 Visibility(可见性)由首字母大小写静默决定。 理解这 4 件事的彼此关系,就掌握了一个 Go 项目骨架。
