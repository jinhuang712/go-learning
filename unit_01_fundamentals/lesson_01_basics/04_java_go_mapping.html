📋 详细对照表

Java 关键字 / 概念Go 中的对应实现说明
classstructGo 没有类的概念,通过结构体组合数据
public / private首字母大小写大写=公开 · 小写=包内私有
extends 继承结构体嵌套(组合)Go 崇尚组合优于继承,没有 extends
implements隐式实现实现接口方法即自动满足接口(Duck Typing)
this方法接收者 Receiver必须显式声明 func (u *User) ...
static包级变量/函数直接定义在 package 级别即可
finalconst (部分对应)仅支持基本类型,不支持不可变对象
try/catch/throw多返回值 error + panic/recover主要靠 error 显式处理;panic 仅用于不可恢复故障
finallydefer函数退出前执行清理逻辑
void无返回值留空即可
while / do-whileforGo 只有 for;for {} = while(true)
enumconst + iota无原生枚举,用常量组配 iota 模拟

图 · 继承 (Java) vs 接口隐式实现 (Go) 的范式差异
迁移要点 Java 工程师转 Go 最大的卡点是:试图用「类继承树」组织代码。 在 Go 里这是 anti-pattern。正确姿势:用小接口 + 组合, 让具体类型通过实现方法被多个接口"自动"满足。
