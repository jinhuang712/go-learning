1.1 变量、常量与基本数据类型

1.1 变量声明

Go 提供多种变量声明方式,旨在简化代码:

  • 显式声明: var name string = "Go" (类似 Java String name = "Go";)
  • 类型推断: var name = "Go" (类似 Java var name = "Go";)
  • 短变量声明: name := "Go" GO 特有 最常用,仅限函数内使用

1.2 常量与枚举 (const & iota)

常量声明:使用 const 关键字。常量的可见性规则与变量完全一致,由首字母大小写决定:

  • const pi = 3.14159 小写,仅当前包内可见,类似 Java private
  • const Pi = 3.14159 大写,其他包可导入,类似 Java public
  • 函数内部声明的 const,只是该函数的局部常量。

枚举模拟 (iota):Go 没有 enum 关键字。iota 是 Go 的内置常量生成器。

  • 当代码中遇到 const 关键字时,iota 被重置为 0。
  • const 块中每新增一行常量声明,iota 就自动 +1。
const (
    Sunday = iota // 0 (iota 被重置为 0)
    Monday        // 1 (未写赋值表达式,默认延续上一行的规则,此时 iota=1)
    Tuesday       // 2 (此时 iota=2)
)

1.3 基本数据类型

Go 的基本数据类型与 Java 类似,但有自己的特点:

分类Go 类型Java 对照说明
整型int / int8/16/32/64int / longint 大小取决于操作系统 32/64 位
无符号uint / uint8 ...无原生Java 无无符号整型
浮点float32 / float64float / double推荐 float64
布尔boolbooleantrue / false
字符串stringString不可变字节切片,默认 UTF-8
字符byte = uint8byteASCII / 二进制
字符rune = int32charUnicode 码点
Java 对照 Java 的 String 底层是 char[] (UTF-16 编码,每个 char 占 2 字节); Go 的 string 底层是 []byte (UTF-8 编码,字符宽度变长 1-4 字节)。 所以遍历中文字符串必须用 for _, r := range s 拿 rune,不能用 s[i] 取 byte。

1.4 零值 (Zero Value)

Go 没有 Java 那种「未初始化变量编译报错」的限制。任何变量声明后,自动获得对应类型的零值:

类型零值
数值 (int, float)0
boolfalse
string"" (空字符串,非 nil)
指针 / Slice / Map / Channel / Func / Interfacenil
结构体每个字段递归取零值
坑点:nil Slice vs 空 Slice var s []int 是 nil slice,可以直接 append,但不能 s[0]=1。 s := []int{} 是非 nil 的空 slice。两者长度都是 0,但 s == nil 结果不同!

📝 练习题

  1. 用 iota 定义一个表示文件权限的常量组:Read = 1, Write = 2, Execute = 4 (位移运算)。
  2. 声明一个字符串 s := "你好Go",分别用 len(s) 和 len([]rune(s)) 输出,理解 byte 与 rune 的差异。
