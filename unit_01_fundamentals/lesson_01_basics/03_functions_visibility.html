1.3 函数与可见性

3.1 函数与多返回值

Go 的函数签名设计与 Java 有所不同,类型写在变量名后面。

  • 基本声明:func add(a int, b int) int
  • 简写:func add(a, b int) int
  • 多返回值:Go 原生支持,在 Go 中极其常见,通常返回 (结果, 错误)。
func divMod(a, b int) (int, int) {
    return a / b, a % b
}

// 调用时接收
q, r := divMod(10, 3)

Java 对照 Java 要返回多个值,通常要么用 Pair / Tuple 工具类,要么自定义包装类,要么用 out 参数。 Go 的多返回值是第一公民,这是 error 显式处理的基础设施。

3.2 可见性 (Visibility)

Go 没有 public、private 或 protected 关键字。它通过标识符的首字母大小写来决定可见性(仅在包级别生效)。

图 · 首字母大小写决定包级可见性
Go 写法对应 Java可见范围
func PublicFunc()public所有 import 它的包都能调用
func privateFunc()包私有(类似 Java 默认/包私有)仅当前包内可见
type User struct { Name string; age int }同上Name 公开 · age 私有
坑点 JSON 序列化时,json.Marshal 只会序列化导出字段(大写开头)。 如果字段写成小写 name,JSON 输出永远是空 {}。
