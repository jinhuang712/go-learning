Lesson 3 · 结构体与接口 Structs & Interfaces

本课程主要介绍 Go 的面向对象编程 (OOP) 核心:结构体、方法、接口以及组合。这与 Java 基于类的继承体系有着本质的区别。

学习地图 Go 没有 class / extends:一切由 struct + interface + 组合(嵌入)拼出来。 Section 1 拆 struct 的内存布局、方法集与组合;Section 2 直击接口的两个胖指针 (iface/eface) 与 nil 大坑。
