Lesson 3 · Select 多路复用与超时控制

select 是 Go 唯一能「同时等待多个 channel 事件」的语法,本质上是 channel 的多路复用器。 这一课从语法、随机选择规则讲起,过渡到生产中最常见的几种模式(超时控制、非阻塞读写、多路 fan-in、退出信号), 再覆盖最容易踩的几个坑——nil channel、空 select{}、循环里的 time.After 内存泄露。

Java 对照 Java 最接近的东西是 java.nio.channels.Selector——但那是基于 IO 多路复用 (epoll/kqueue) 的类库, 只能用于网络 fd,而且要显式注册、按 key 处理。 CompletableFuture.anyOf() 倒是「多路等待」的高阶抽象,但开销远高于 select。 Go 的 select 是语法级别的多路复用,适用于任意 channel,且开销极低。

🎯 学习目标

  • 能用 select 写超时、退出、非阻塞、多路 fan-in 四类经典模式。
  • 理解多 case 就绪时的随机选择机制,能解释它如何避免饥饿。
  • 知道 nil channel 在 select 中「永远不被选中」的特性,能借此动态启用/禁用 case。
  • 知道循环里 time.After 为什么泄露,能用 time.NewTimer + Reset 修复。
