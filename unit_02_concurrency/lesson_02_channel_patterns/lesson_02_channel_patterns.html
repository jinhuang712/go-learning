Java 视角导览 Channel 在 Java 里的对应物零零散散:
  • 无缓冲 Channel ↔ SynchronousQueue (容量 0,必须握手)
  • 有缓冲 Channel ↔ ArrayBlockingQueue / LinkedBlockingQueue
  • close(ch) 广播 ↔ 无直接对应,Java 用 CompletableFuture + 中断信号拼凑
  • chan<- / <-chan ↔ Java 无编译期方向约束
Go 用一种统一的语言原语覆盖了 Java 里多个 API 的功能。
