2.3 有缓冲 Channel(异步通信)

有缓冲 channel 是 make(chan T, capacity) 创建的。底层是一个环形缓冲区 (ring buffer)。在缓冲未满时,发送不阻塞;在缓冲非空时,接收不阻塞——这是半异步的通信。

1. 阻塞规则速记

状态发送 ch <- v接收 <-ch
缓冲空不阻塞阻塞 (除非有 sender 等)
缓冲半满不阻塞不阻塞
缓冲满阻塞不阻塞

2. Ring Buffer 内部结构

Go runtime 的 hchan 结构体内部用一个固定长度的数组当循环队列,两个游标 sendx (下一个写入位置) 和 recvx (下一个读取位置) 在数组里转圈。这是非常经典的 ring buffer 实现:

Java 对照 ArrayBlockingQueue 和 Go 有缓冲 channel 原理几乎一样——都是定长环形数组 + 满/空时阻塞。 区别在于 Go 把它做成了语言原语,并把方向约束、close 广播这些能力也加进来,使用更顺手。

4. 经典用法

用法 1:任务队列 (降低生产者-消费者耦合)

jobs := make(chan int, 100)  // 缓冲 100 个任务

// 5 个 worker
for w := 0; w < 5; w++ {
    go func(id int) {
        for j := range jobs {
            fmt.Printf("worker %d 处理 %d\n", id, j)
            time.Sleep(10 * time.Millisecond)
        }
    }(w)
}

// 生产者发送 1000 个任务,因为有缓冲,不会立刻阻塞
for i := 0; i < 1000; i++ {
    jobs <- i
}
close(jobs)

用法 2:信号量 (限制并发数)

sem := make(chan struct{}, 3)  // 最多 3 个并发

for i := 0; i < 10; i++ {
    sem <- struct{}{}  // 拿令牌 (满了就阻塞,达到限流)
    go func(id int) {
        defer func() { <-sem }()  // 还令牌
        fmt.Println("处理", id)
        time.Sleep(time.Second)
    }(i)
}

用法 3:批量收集结果

results := make(chan int, 5)
for i := 0; i < 5; i++ {
    go func(n int) {
        results <- n * n  // 即使没人接收,也能先放进缓冲
    }(i)
}

// 之后慢慢取
for i := 0; i < 5; i++ {
    fmt.Println(<-results)
}

5. 容量到底设多大?

容量选择原则
  • 容量 0 (无缓冲):要强制同步、握手、传递可见性
  • 容量 1:做信号量、互斥锁、最新值缓存
  • 容量 = worker 数:任务分发,避免生产者阻塞
  • 容量 = 处理速率差 × 时间窗口:抗突发流量
千万不要因为「怕阻塞」就把容量设很大——这只是把背压问题往后推。

6. 生产坑点

坑点 1:容量过大掩盖问题 make(chan T, 100000) 看起来「永远不会阻塞」,但消费者跟不上时,内存会被快速吃光。 容量是背压的工具,不是免阻塞的银弹。
坑点 2:缓冲 channel 的 close 时机 关闭一个还有数据的缓冲 channel 不会丢数据:接收方可以继续 for range 把残留消费完,然后退出循环。 但关闭后不能再发送,会 panic。
坑点 3:缓冲满了导致 goroutine 泄露 
ch := make(chan int, 1)
ch <- 1   // 缓冲满了
go func() {
    ch <- 2  // 永远阻塞 → goroutine 泄露
}()
解决:用 select + default 提供 fallback,或用 context 控制超时退出。

📝 练习题

  1. 用 make(chan struct{}, 3) 实现限流器:限制最多 3 个 HTTP 请求并发,其他请求排队。
  2. 测试容量影响吞吐:生产者发送 10000 个数,消费者每个处理 1ms,分别用容量 1 / 10 / 100 / 1000 跑,观察总耗时。
  3. 实现「最新值缓存」:1 容量的 channel 只保留最新一个值,新值来了把旧值挤掉 (提示:select + default + 取出旧值)。
