Lesson 1 · Goroutine & CSP 模型基础

这一课开启 Unit 2「并发与并行」之旅。我们从 Go 并发模型的最小单元 — Goroutine 入手,先把 Java 1:1 线程模型 与 Go M:N 协程模型彻底对照清楚,再下钻到 G-M-P 调度器与最常见的泄露陷阱。

学习地图 本 Lesson 拆成 3 个 Section: 概念入门 → 调度生命周期 → 泄露体感。 建议按顺序通读后,再去看 code/ 下的可运行 Demo。
Java 对照 Java 21 引入了 Virtual Thread 才让 Java 拥有类似 Goroutine 的轻量级线程能力。 但在 Java 21 之前(以及当前生产环境大量使用的 Java 8/11/17 平台线程模型), new Thread() 是 1:1 映射 OS 线程,栈 1MB 起,上万并发就会 OOM。 Goroutine 默认 2KB 栈,Go runtime 在用户态把成千上万个 G 多路复用到少数 M 上,这是数量级的差距。
