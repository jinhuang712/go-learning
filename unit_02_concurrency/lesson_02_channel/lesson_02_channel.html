Lesson 2 · Channel 模式与底层原理

Channel 是 Go CSP 并发模型的核心通信原语。这一课从 channel 基础语法,推进到工业级常用模式 (生产者-消费者、Fan-in/Fan-out、信号量、Worker Pool),最后下钻到 runtime 里的 hchan 结构体,把环形缓冲区和等待队列看个明白。

Java 对照 Java 程序员对 Channel 最贴近的类比是 java.util.concurrent.BlockingQueue: put() / take() 阻塞,容量满阻塞写、容量空阻塞读。 不过 Java 的设计哲学是共享内存 + 锁,Channel 只是辅助; Go 反过来,「Don't communicate by sharing memory; share memory by communicating」 — 用 Channel 作为主要同步原语。
