Lesson 3 · Select 多路复用与超时控制

本课聚焦 Go 并发的「控制层」原语 —— select。它不是普通的 switch,而是 Go 语言为多路 Channel I/O 设计的专用语句:能同时等待多个 Channel,谁先就绪走谁,配合 time.After / default 还能实现超时、非阻塞、扇入扇出等关键模式。

学习地图 Lesson 3 的 5 个 Section 由浅入深:语法骨架 → 超时控制 → 非阻塞 → Fan-in 合并 → Fan-out 分发。 其中超时模式和 Fan-out 是生产环境最高频使用的两个。

图 · Lesson 3 的推进顺序:语法 → 超时 → 非阻塞 → 拓扑(Fan-in / Fan-out)
Java 对照 Go 的 select 大致对应 Java NIO 的 Selector,但作用对象不同:
  • Java Selector.select() 多路复用底层 IO fd (Reactor 模式)
  • Go select {} 多路复用语言层 Channel (CSP 模式)
超时方面,Java 用 Future.get(timeout, TimeUnit) 抛 TimeoutException,Go 则把超时降级成一个普通的 Channel(time.After) 直接参与 select 抢答。

🎯 一句话总结

为什么 select 重要 没有 select,Channel 只能一对一同步;有了 select,Channel 才真正具备多路复用 + 超时 + 非阻塞三大能力, 而这三件事正是工程级并发(超时、取消、汇聚、分发)的全部基石。
context(下一课 L4) 内部正是用 select <-ctx.Done() 实现取消传播。
