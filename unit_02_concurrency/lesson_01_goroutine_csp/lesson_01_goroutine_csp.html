Java 视角的预热 Java 并发=「Thread + synchronized + wait/notify + CountDownLatch」,核心是共享内存 + 锁。 Go 并发=「goroutine + channel + sync.WaitGroup」,核心是通过通信共享内存。 整套思维模型都不同——本课就是来完成这个翻译的。
